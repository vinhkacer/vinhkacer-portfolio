Đăng Nhập Quản Trị

Hệ thống kết nối trực tiếp với GitHub Repository vinhkacer/vinhkacer-portfolio độc lập trên Cloudflare Pages.

Cách tạo GitHub Token (chỉ mất 1 phút):
  1. Truy cập GitHub > Personal Access Tokens (Classic) ↗
  2. Đặt tên Note (ví dụ: Portfolio CMS).
  3. Tích chọn quyền: repo (Full control of private repositories).
  4. Cuộn xuống dưới chọn Generate token và dán chuỗi token vào ô trên.
